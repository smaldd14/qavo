## How to refresh

1. For each document, compare its current version or last-modified date with the table.
2. For a changed document, read the changes. Update the feature files that it feeds. Do not copy credentials, customer data, or screenshots.
3. Update the version and the imported date in the table.

If an agent cannot reach a document (no connector or no access), a person exports it to a file and gives the agent the path.
